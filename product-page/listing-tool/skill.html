選購前先看 skill

檔案：londonimg-train-list.zip　·　用途：寫商品描述最下面那排「選購前先看」（左右滑的白色文字卡，以前叫小火車）。有兩種用法：一題一題回答它問的商品問題；或給它同款商品的網址，它打開那一頁，讀規格和商品特色的圖，寫成卡片。

下載選購前先看 skill（.zip）

下載後不要解壓縮，直接上傳整個 zip。自己解壓再壓回去，裡面的資料夾名稱可能會變，上傳就會失敗。下載完如果看到的是資料夾、不是 .zip（Mac 的 Safari 預設會自動解壓縮），改用 Chrome 再下載一次。怎麼用，看下面的使用方式。

換新版時，照下面「更新 skill」直接上傳新的 zip，不用先刪掉舊的。

安裝方式（claude.ai 網頁／桌面 App）

  1. 打開 claude.ai，先到 Settings（設定）→ Capabilities，打開 Code execution and file creation。沒開的話 skill 不會跑。
  2. 左邊側欄點 Customize → 選 Skills。
  3. 右上角點 Add 按鈕 → 下拉選最下面那個 Upload a skill（不是上面的 Create with Claude／Write skill instructions）。
  4. 挑剛下載的 londonimg-train-list.zip（整顆 zip、不要解壓縮）→ 看到 londonimg-train-list 出現、開關是開的 → 完成，回對話就能用。

更新 skill（直接上傳新版）

skill 不會自動更新。收到新版 zip 時，直接上傳新的就好，不用先刪掉舊的。

  1. 回 claude.ai 左邊側欄 Customize → Skills（跟安裝是同一個地方）。
  2. 右上角 Add → Upload a skill → 挑新的 londonimg-train-list.zip（整顆 zip、不要解壓縮）。下載資料夾裡有好幾個的話，挑最新下載的那個。
  3. 看到 londonimg-train-list 在清單上、開關是開的 → 完成，就是最新版了。

上傳完沒看到新版？桌面 App 請完全關閉再重開（或開一個新對話）；網頁版按 ⌘⇧R（Windows Ctrl+Shift+R）強制重新整理。

使用方式

選購前先看（londonimg-train-list）

「選購前先看」是商品描述最下面那排左右滑的白色文字卡，以前叫「小火車」。有兩種用法，看你開頭給它什麼。

用法一：一題一題回答

  1. 開新對話，直接說：幫 [短名] 寫選購前先看。
    例：幫 明岳殼 寫選購前先看。說「寫小火車」也可以。
  2. 它先問四件事，一次回完：要回答幾題（5、10、15、20 選一個）、商品全名和短名、手機殼還是其他商品、這頁用 HTML 版還是長條圖版（有沒有兩個版本可以選）。
  3. 接著一次問一題。先回答，再補一句原因或用法。不知道或這個商品沒有，就說「跳過」。規格和適用機型不會問，那兩節在上架工具的表裡填。
  4. 講到軍規、認證、保固這類要有報告或公司資料的字，它會停下來問。
  5. 全部問完，它交一張對照表和一個連結。點連結，上架工具會打開，問答自己填好。

用法二：給同款商品的網址

  1. 開新對話，說要寫選購前先看，同時貼上同款商品在別的賣場的網址。
    例：幫 明岳殼 寫選購前先看，同款商品的網址是 https://（那一頁的網址）
  2. 它先問三件事：我們這頁用長條圖版還是 HTML 版、短名要叫什麼、手機殼還是其他商品。題數、全名、有沒有兩個版本都不問。
  3. 它只打開你給的那一頁，讀「商品規格」分頁的字和「商品特色」的圖，寫成卡片，再給你一個連結。你不用傳圖，也不用貼規格。
  4. 點連結，上架工具會打開，讀到的卡都放好了。每張卡下面有原文和出處，一張一張按：
    對：我們這款也是這樣。只有按「對」的卡會放進要複製的語法。
    這款沒有：我們這款沒有，這張不放。
    不確定：先不放。
  5. 有數字的卡、寫到別的牌子配件能不能用的卡，一開始是「不確定」，對過包裝或公司資料才按「對」。
  6. 想改字，直接在工具的格子裡改，改完一樣要按「對」。不要再點一次連結：重新打開，按好的核對會全部回到還沒核對。
  7. 空著的題目、顏色、規格和適用機型，照工具的表自己填。我們有兩個版本的話，最上面那題自己選；講到 MagSafe、支架、磁吸的卡，看兩款是不是都這樣。

連結點不了、打不開

  1. 連結變成普通字、點不了：複製連結下面框框裡的整段網址，貼到瀏覽器的網址列，一樣會打開。
  2. 打不開：回對話跟它說，它會再給一次同一條連結。
  3. 還是打不開：用法一照對照表最右邊那欄，一題一題填進工具。用法二它會列一張「這些卡還沒核對」的表，對著原頁看過，對的才自己填進工具。

放進後台

  1. 選購前先看的卡會跟商品描述的其他區塊一起，放進上架工具的「複製語法」。核對、填完之後，照第一次用說明第 5 節，按「複製語法」，貼進後台商品描述的 HTML 原始碼。
