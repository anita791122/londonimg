開上架工具｜第一次用說明
商品頁設定

Claude Skill

這個 skill 也能產「商品頁設定」（給搜尋引擎看的四欄），規則跟上架工具的指令是同一份。
下載 → 安裝 → 使用三步驟。

下載區

檔案：londonimg-product.zip　·　用途：輸入商品資訊，產出 SHOPLINE 後台「網路搜尋最佳化」的四欄（標題／簡介／關鍵字／描述性網址）。
已經裝過舊版（會產商品描述的那一版）的人，要照下面「更新 skill」先刪掉舊版、再上傳新版。

下載 Skill（.zip）

下載後不要解壓縮，直接上傳整個 zip。自己解壓再壓回去，裡面的資料夾名稱可能會變，上傳就會失敗。下載完如果看到的是資料夾、不是 .zip（Mac 的 Safari 預設會自動解壓縮），改用 Chrome 再下載一次。

安裝方式（claude.ai 網頁／桌面 App）

🎬 影片示範：跟著做

  1. 打開 claude.ai，先到 Settings（設定）→ Capabilities，打開 Code execution and file creation。沒開的話 skill 不會跑。
  2. 左邊側欄點 Customize → 選 Skills。
  3. 右上角點 Add 按鈕 → 下拉選最下面那個 Upload a skill（不是上面的 Create with Claude／Write skill instructions）。
  4. 挑剛下載的 londonimg-product.zip（整顆 zip、不要解壓縮）→ 看到 londonimg-product 出現、開關是開的 → 完成，回對話就能用。

更新 skill（刪掉舊版 → 上傳新版）

skill 不會自動更新。收到新版 zip 時，要先把舊的刪掉再上傳新的，否則會用到舊版、或清單出現兩個同名 skill。

① 先刪掉舊的

  1. 回 claude.ai 左邊側欄 Customize → Skills（跟安裝是同一個地方）。
  2. 在清單找到 londonimg-product，點它那一列右邊的 •••（三個點；滑鼠移上去會出現）叫出選單。
  3. 選 Delete（刪除）→ 跳出確認就按確認刪除。清單上的 londonimg-product 消失＝舊版清乾淨了。

② 再上傳新的

  1. 一樣在 Skills 右上角 Add → Upload a skill → 挑新的 londonimg-product.zip（整顆 zip、不要解壓縮）。下載資料夾裡有好幾個的話，挑最新下載的那個。
  2. 看到 londonimg-product 重新出現、開關是開的 → 完成，就是最新版了。

刪掉會影響我的對話紀錄嗎？不會。刪的只是這個 skill，你的對話都還在。刪錯或想換版本，隨時再上傳 zip 即可。

上傳完沒看到新版？桌面 App 請完全關閉再重開（或開一個新對話）；網頁版按 ⌘⇧R（Windows Ctrl+Shift+R）強制重新整理。

使用方式

skill 裝好後，照下面做就能產出商品頁設定：

  1. 在 Claude 對話直接說：幫 [商品名] 寫商品頁設定。
    例：幫 YU 360°無段支架手機殼 寫商品頁設定，賣點是 360度支架、MagSafe、防摔。
    有分機型的商品，把上架工具「商品摘要」分頁裡的「適用機型」那一行一起貼給 Claude。
  2. Claude 會（必要時）反問商品資訊，然後產出商品頁設定四欄：標題／簡介／關鍵字／描述性網址，每欄一鍵複製。
  3. 貼回後台：後台 → 商品 → 編輯該商品 → 網路搜尋最佳化，四欄分別貼上。已經上架的商品，「描述性網址」那一欄先不要貼。

產出已內建規則：標題不塞促銷字、標題的機型只寫最新一代、網址只用小寫英文、數字和連字號 -。已經上架的商品不要自己改網址：網址一改，舊的連結和 Google 排名會斷，要另外設轉址（讓舊網址自動跳到新網址），先問工具負責人。
