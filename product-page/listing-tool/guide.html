新上架的商品，商品描述、商品摘要和網路搜尋最佳化的四欄，都在上架工具裡產生。
第一次用說明

商品頁上架工具

工具做三件事：產出「商品描述」的語法、「商品摘要」的文字，和「網路搜尋最佳化」的四欄。你把圖片網址和文字填進表單，按複製，再貼進後台。
工具不會自己寫進後台，也不會動到後台的價格和規格選單。

打開上架工具

目前只在 Chrome 上測過，建議用 Chrome 開。工具要讀圖片的尺寸，所以要有網路。
後台「網路搜尋最佳化」的四欄，工具直接產好，不用另外開 Claude。做法看 第 6 節。

1先準備照片

照片要夠大，不然在高解析螢幕（Mac、手機）上會糊。工具會自己讀每張圖的尺寸，太小會出現紅字。

放在哪一區圖框最小尺寸（寬 × 高，px）
Hero 大圖橫圖，商品放中間、上下左右都多留空間（手機版裁左右，桌機版裁上下）1920 × 720
棋盤格（D～G）3:2 橫框1320 × 880
其他特色卡片1:1 方框900 × 900
比較區卡片4:3 橫框1350 × 1012

拍攝建議：遠一點拍；同一個商品的照片，用同一個背景或同一個顏色；至少帶一點散景。

工具右邊的「圖片規格」分頁也有這張表。

2拿到圖片網址

工具要的是 SHOPLINE 上的圖片網址。拿網址的方法：

  1. 後台 → 商品 → 編輯這個商品 → 商品描述。
  2. 點工具列的「插入圖片」，把這個商品要用的圖都上傳。
  3. 點右上角的 </>，切到 HTML 原始碼。
  4. 每張圖都是一段 <img src="https://img.shoplineapp.com/…">。只複製雙引號裡面的網址。
網址的結尾要是 original.副檔名（例如 original.png、original.jpg），後面多一段 ?… 沒關係。
網址裡如果是 800x、1080x 這種縮圖網址，工具會標紅字「網址格式不對」，請換成 original 那一串。

剛才插進描述裡的圖，等一下貼語法時會一起被換掉，不用留。

3填表單

  1. 最上面先回答「這個商品有沒有比較區」。比較區是拿同一款商品的兩個版本（例如一般款和進階款）並排比；沒有兩個版本可比，就選「沒有」。
  2. 從上往下填。灰色的字是 B67（YU 360°無段支架手機殼）的例子，照它的格式寫。
  3. 貼上圖片網址之後，工具會讀圖，告訴你夠不夠大。
  4. 大部分的區都有「這個商品要放這一區」的勾，要用就勾，不用就不勾。Hero 和商品摘要一定要放，沒有這個勾；比較區看最上面那題怎麼答。
  5. 加價購區和棋盤格 D～G 一開始是沒勾的。加價購區要放才勾；棋盤格至少要勾一段，不然「複製語法」變不了黑色。
  6. 右邊的預覽可以切手機、平板、桌機三種寬度，大致就是客人看到的樣子。

加價購區（A 區）

  • 要放才勾。勾了之後，按下面清單的「加入」最簡單。要自己貼的話，一行貼一個加價購頁的網址（不是一般賣場的網址）。
  • 工具只認得清單裡的商品。要放新的加價購商品，請找工具負責人加進工具。
  • 清單裡的安心扣【S75】寫著「先不放」，沒有「加入」鈕：它的加價購頁和加購價還沒好。直接貼它的網址會出現紅字，這張卡也不會放進語法。

4看懂「複製語法」按鈕的顏色

按鈕長這樣意思
複製語法全部處理好了，可以複製。
複製語法｜有 3 項紅字有地方不合規則，要改。
複製語法｜5 欄範例字要換還有 B67 範例的字沒換掉。
複製語法｜還有 2 處待填還有格子空著。
複製語法｜還在讀 2 張圖圖片還在讀尺寸，等幾秒。

按鈕是紅色或橘色時，第一次按不會複製，按鈕下面會先出現一行紅字提醒。10 秒內再按一次，才會複製。

同時有好幾種問題時，按鈕只顯示最要緊的那一種：先紅字，再範例字，再待填。改完紅字後變成橘色是正常的。

「商品摘要」分頁的「複製摘要」也是同一套顏色和規則（只看摘要用得到的欄位）。

右邊的「檢查清單」分頁會列出每一項問題。點一下，就會跳到那一格。

5貼進後台

  1. 後台原本的描述如果要留，先複製起來，存到別的地方。電腦一次只記得一份複製的東西，後複製的會蓋掉先複製的。
  2. 回到工具，按「複製語法」。
  3. 後台商品描述 → 右上角 </> 切到 HTML 原始碼 → 把裡面原本的內容全選 → 貼上。
  4. 回到工具，點右邊的「商品摘要」分頁 → 按「複製摘要」。
  5. 貼進後台的「商品摘要」欄，原本有字的話，全選後貼上取代。這是另一格，不是商品描述。
  6. 存檔。

後台的商品名稱由你自己取，工具不會產。

用這個工具做的第一個商品，先存成隱藏商品。
把網址傳給工具負責人，看過沒問題再上架。

6產「網路搜尋最佳化」四欄

後台商品編輯頁有一區「網路搜尋最佳化」，裡面四格：標題、簡介、關鍵字、描述性URL。這四格是給 Google 看的。工具照你填的表單直接產好，不用另外開 Claude。

  1. 先把表單填好：Hero 的商品名、商品摘要的產品特色、適用機型表。四欄從這些資料來，賣點寫得越多，四欄越完整。
  2. 點工具右邊的「搜尋最佳化」分頁，看上面三個小欄位：
    • 品類：工具會從商品名猜（例如「手機殼」）。猜錯就自己選。
    • 這個賣場有一般版和 MagSafe 版：同一個賣場有沒有磁吸的版本也有賣，就勾。勾了，標題和簡介會寫「可選 MagSafe 版」。
    • 網址英文：沒填就照商品名猜。工具提醒「網址只有品牌和品類」時，填這個商品的特色，例如極地冰岩殼可以填 ice-rock。
  3. 四格底下的字是建議，不是錯誤。可以照著改，也可以不改，都能複製。格子裡的字可以直接改，改過的會記住。
  4. 四格各自按「複製」，貼進後台「網路搜尋最佳化」的「繁體中文」分頁，照欄位名對應貼，存檔。

想讓文字讀起來更順，分頁最下面有「想讓 Claude 寫得更順（選用）」：按「複製指令」貼進 claude.ai，Claude 會照同一份規則重寫四欄。不用也可以。

已經上架的商品，「描述性URL」先不要換。
網址一換，舊連結和 Google 排名會斷。要換先問工具負責人。新商品照貼。

7換下一個商品之前，先「存成檔案」

工具會自動把填到一半的內容存在這台電腦的瀏覽器裡，但只記得一份。開始填下一個商品，上一個就被蓋掉了。

  1. 做完一個商品，按工具右上角的「存成檔案」。會下載一個 上架草稿_商品名.json，檔名用的是 Hero 區填的商品名。
  2. 要回來改，按「讀取草稿檔」，選那個檔。讀取會直接換掉畫面上現在的內容，不會先問；現在這份還要的話，先按「存成檔案」。
  3. 要開始新的商品，按「清空重填」。

換電腦或清掉瀏覽器資料，瀏覽器裡那一份就沒了。存成檔案的不會。

8卡住的時候

把整個畫面截圖，紅字那一格和左上角的版本日期都要看得到，傳給工具負責人。

工具左上角、標題旁邊，寫著版本和日期（「基本版 v0.1」後面那個日期）。工具更新後，重新整理網頁就是最新版。加價購的價格是哪一天跟商城對過的，寫在加價購區裡（要先勾「這個商品要放這一區」才看得到）。
