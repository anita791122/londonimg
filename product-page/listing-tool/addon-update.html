加價購區

加價購區更新器

商品描述最上面那一排橫滑的加價購卡片。貼上這次要放的商品網址，工具產出整段語法，你再到後台把舊的那段換掉。一次換很多頁時，卡片填一次就好，然後一頁一頁換。

iPhone 18 專頁的 35 個賣場不要貼這個區塊。

1這次要放的卡

一行貼一個加價購商品的網址，順序就是卡片從左到右的順序。手機殼那一組、Z35 錶帶頁那一組，可以直接按下面的按鈕帶入。

預覽

只是大概的樣子，實際以前台為準（前台的英文和數字是網站字體）。

2這一頁

這一頁的商品描述裡，原本有加價購區嗎？

【ZZ35】（/products/z35）最上面有舊的圖片版加價購區（三張圖）：那個不算，第一次放選「沒有」，新的貼在它上面，舊的三張圖留著。

算成效的 8 頁（B67、K50s、S12、D12、D43、B53、Z19、N08）要放同一組卡、同樣的順序。鏡頭環 N08、冰盾貼 Z19 這兩頁，區塊裡有一張連回自己的卡，留著。

用哪一種方法換？
  1. 後台打開這個商品 → 商品描述 → HTML 原始碼。
  2. 點一下那一格裡面，按 ⌘A 全選（只會選到格子裡的字），再按 ⌘C（Windows 是 Ctrl+A、Ctrl+C）。
  3. 貼到下面這一格。工具只換加價購區，其他的字一個都不動，會在下面告訴你。

整段貼不進來、或工具說找不到加價購區的時候，才用這個方法。

  1. 後台打開這個商品 → 商品描述 → HTML 原始碼。
  2. 找到 <div style="position:relative;width:100vw;left:50%;margin-left:-50vw;overflow-x:clip"> 這一串（clip 後面直接是 ">），從它最前面的 < 開始，往下選到加價購區的結尾（最後一張卡後面的幾個 </div>），按 ⌘C（Windows 是 Ctrl+C）。上架工具做的頁，最前面還有一個很像的整頁外框（後面多了 background 等設定），不是那一個。
  3. 貼到下面這一格，工具會告訴你選得對不對。不用自己數 </div>，每一頁的結尾不一樣，工具會算。

3複製，貼回後台

  1. 回到後台的 HTML 原始碼，點一下那一格裡面，按 ⌘A 全選，再按 ⌘V，整段換成工具給的。
  2. 存檔，記下存檔的日期和時間。
  3. 用手機打開前台看：卡片都在、可以滑到最後一張；「Add-on Deals」只出現一次；下面原本的內容都還在。

  2. 反白不見了，就照剛剛的範圍重選一次（工具上面說「選得剛好」的那一段），再按 ⌘V。
  3. 存檔，記下存檔的日期和時間。
  4. 用手機打開前台看：卡片都在、可以滑到最後一張；「Add-on Deals」只出現一次；下面原本的內容都還在。

  2. 存檔，記下存檔的日期和時間。

4換品紀錄
