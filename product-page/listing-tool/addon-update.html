加價購區

加價購區更新器

這個工具用來換商品描述最上面那排加價購卡片。第 1 步放這次的卡，一輪只做一次。第 2 到 4 步每一頁做一次：先選這一頁原本有沒有加價購區，再把後台的商品描述整段貼進來，工具換好加價購區，你整段貼回去存檔，再記一列換品紀錄。

1這次要放的卡（這一輪做一次）

一行貼一個加價購商品的網址，順序就是卡片從左到右的順序。手機殼那一組、錶帶＋錶框組兩頁（【Z35】、【ZZ35】）那一組，可以直接按下面的按鈕帶入。Z35 兩頁 10/20 已經換好。

這 8 頁要比較換卡前後賣得怎樣（B67、K50s、S12、D12、D43、B53、Z19、N08），要放同一組卡、同樣的順序。鏡頭環 N08、冰盾貼 Z19 這兩頁，區塊裡有一張連回自己的卡，留著。

預覽

只是大概的樣子，實際以前台為準（前台的英文和數字是網站字體）。

2換哪一頁（每一頁做一次）

第 2 到 4 步每一頁做一次，做完按最下面的「換下一頁」。

這一頁的商品描述裡，原本有加價購區嗎？

【ZZ35】（/products/z35）的舊圖片版加價購區（三張圖）工具不算它。10/20 已經在它上面放好新的加價購區，之後再換這一頁要選「有」，舊的三張圖留著。

  1. 後台打開這個商品 → 商品描述 → HTML 原始碼。
  2. 點一下那一格裡面，按 ⌘A 全選（只會選到格子裡的字），再按 ⌘C（Windows 是 Ctrl+A、Ctrl+C）。
  3. 貼到下面這一格。工具只換加價購區，其他字一個都不動。找到幾張舊卡、有沒有動到別的字，格子下面會寫。
整段貼不進來的時候（備用方法）

整段描述貼不進來，或工具說加價購區的標籤對不起來（多半是沒全選到、貼進來少了一截），重新全選貼上還是一樣，才用下面的方法。工具說找不到外框、有兩個加價購區、或加價購區長得不對的時候，下面的方法也解決不了，請找 Anita。

  1. 後台打開這個商品 → 商品描述 → HTML 原始碼。
  2. 找到這一串：<div style="position:relative;width:100vw;left:50%;margin-left:-50vw;overflow-x:clip">。要 clip 後面直接接 "> 的那一串。上架工具做的頁，最前面還有一個很像的整頁外框，後面多了 background 等設定，不是那一個。
  3. 從這一串最前面的 < 開始選，往下選到最後一張卡後面那幾個 </div>，按 ⌘C（Windows 是 Ctrl+C）。
  4. 貼到下面這一格，工具會告訴你選得對不對。不用自己數 </div>，每一頁的結尾不一樣，工具會算。

不用貼舊的描述進來。第 3 步複製語法後，貼在後台描述的最前面。

3複製，貼回後台

  1. 回到後台的 HTML 原始碼，點一下那一格裡面，按 ⌘A 全選，再按 ⌘V（Windows 是 Ctrl+A、Ctrl+V），整段換成工具給的。
  2. 存檔。看一下存檔的時間，第 4 步要填。
  3. 用手機打開前台看：卡片都在、可以滑到最後一張；「Add-on Deals」只出現一次；下面原本的內容都還在。
  1. 回到後台的 HTML 原始碼。剛剛選的那段如果還反白，直接按 ⌘V（Windows 是 Ctrl+V）貼上。
  2. 反白不見了，就照剛剛的範圍重選一次（工具上面說「選得剛好」的那一段），再按 ⌘V（Windows 是 Ctrl+V）。
  3. 存檔。看一下存檔的時間，第 4 步要填。
  4. 用手機打開前台看：卡片都在、可以滑到最後一張；「Add-on Deals」只出現一次；下面原本的內容都還在。
  1. 後台打開這個商品 → 商品描述 → HTML 原始碼，游標放在最前面（第一行的第一個字前面），按 ⌘V（Windows 是 Ctrl+V）。
  2. 存檔。看一下存檔的時間，第 4 步要填。
  3. 用手機打開前台看：卡片都在、可以滑到最後一張；「Add-on Deals」只出現一次；下面原本的內容都還在。

4換品紀錄

每換完一頁，填後台存檔的日期和時間，複製這一段，貼到 Anita 的 Notion，放在「換品紀錄」標題下面。這一輪的第一頁會多帶幾列這次的卡片清單，一起貼就好，之後的頁不會再帶。要比較換卡前後賣得怎樣，得知道每一頁是哪天換上去的。

卡片和名字留著，只清掉要換的商品頁網址、貼進來的描述、存檔的日期和時間。要換一組卡從頭來，按第 1 步的「清空重填」。重新整理頁面會全部清空。
