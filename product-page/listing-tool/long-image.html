跳到預覽與複製

倫敦印象｜長條圖版用上架工具

2026-10-19 使用說明
怎麼用這個工具只產生語法，不會寫進後台，也不會碰價格和規格。
  1. 這一頁給長條圖版的賣場用（商品描述是一張張直式長圖的那種）。做的是貼在長圖下面的四區：選購前先看、適用機型、規格表、常見問題。哪一區不放，就把那一區的勾拿掉。
  2. 從上往下填，灰色字是例子。「選購前先看」那一區有寫法建議，寫之前先看一次。
  3. 預覽上方的「複製語法」變成黑色，才是全部填好：沒有紅字、沒有待填。按下去。
  4. 後台打開這個商品 → 商品描述 → HTML 原始碼。游標放在最後面（最後一個字的後面，就是長圖的下方），按 ⌘V（Windows 是 Ctrl+V），存檔。
  5. 用手機打開前台看：四區都在長圖下面，選購前先看可以左右滑到最後一張。

這個商品已經貼過這四區，現在要改內容的話：不要再貼一次（頁面上會有兩份），先找工具負責人。

後台「網路搜尋最佳化」的「簡介」欄如果空著，商城會拿商品描述裡的文字（圖片不算）當成給 Google 的摘要和 LINE 分享預覽的那段字；貼完四區，這四區的字也會被抓進去。請順手把簡介欄填好，填了就不會被描述蓋掉。

預覽最上面那塊灰色是什麼？

那是商品原本的長圖，只在預覽裡，不會被複製。四區會接在長圖下面。商品描述欄左右的留白照前台量的（手機各 22px、平板 35px、桌機 45px）。

字型：英數用系統字。中文寫的是 Noto Sans TC，但 iPhone、Mac 沒有內建它，客人看到的是蘋方（Windows 是微軟正黑）。你的電腦如果自己裝了 Noto，這裡的中文會跟客人看到的不一樣。

和預覽、「複製語法」用的是同一份，一行一個標籤。
