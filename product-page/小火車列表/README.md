# 小火車列表 Skill

問美編商品的問題，把回答寫成完整句子，輸出問答給上架工具用。

現在只放本機，還沒打包、沒有發給同事。

## 內含
- `SKILL.md`：流程、寫法、紅線、輸出格式、交出前的檢查
- `reference/questions.md`：題目、問到第幾題、貼到工具哪一格
- `reference/tone-rules.md`：語氣規則，`londonimg-product/reference/tone-rules.md` 的複本。要改去改本尊，再複製過來
- `check_questions.js`：對齊檢查，不進 zip

## 怎麼試
在 Claude Code 從專案根目錄開對話，說：

> 照 `交付物/product-page/小火車列表/SKILL.md`，幫我做某商品的小火車。

## 題目有兩份，怎麼對齊
工具的固定題在 `上架工具/src/gen.js` 的 `TRAIN_Q`（畫面由 `src/train-form.js` 畫）。skill 的題目在 `reference/questions.md`。

做法是一支檢查：`node check_questions.js`。對不上就列出來、exit 1。下面這些事之後要跑，打包 zip 前也一定要跑：
- 改了 `TRAIN_Q`、選項、字數門檻
- 改了語氣規則（`tone-rules.md`）
- 改了提醒字清單（`seo-geo-rules.md` §6）

它查的是：
- 工具的固定題：問句一字不差，選項都在。skill 自己加的題目 id 用 `c-`／`o-` 開頭，問句不跟固定題撞
- 品類表：每列剛好 3 題，都是問句，不跟其他商品那 7 題撞。碰到電池、發熱、行車、搭機的題（比對飛機、燙、邊充邊用、開車這幾個字）要標「有公司資料才答」，SKILL.md 要有這條規則
- 題數：手機殼每一級 5 題，重量厚度在最少的 5 題裡，其他商品寫的題數對得上
- 紅線字：比較和特色、手機殼、其他商品、品類表，四張表的題目都掃。§6 的字從規則檔讀，其他的（通過、保固、背板、聚碳酸酯、PC、9H、變黃、跌落、公尺、價格、出貨、到貨這類）列在這支裡
- 數字：從 SKILL.md、questions.md 讀出太短門檻、回答、問題、比較的字數和特色項數，跟工具的常數比。那句被改寫到讀不到，也算對不上
- 追問表第一欄跟工具 `YES_ONLY` 逐字比，兩邊都不能多
- 語氣規則和 §6 一樣，沒有內部用語和破折號

它不查的：
- 紅線字的同義說法：這支只比列出來的字，新的講法要自己加進去
- 題目問得好不好，哪些題算安全題（這支只比那幾個字）
- SKILL.md 的追問句、紅線句、例子句寫得對不對，例子有沒有多寫字
