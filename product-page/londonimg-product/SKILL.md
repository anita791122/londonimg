# 倫敦印象｜商品頁設定產生器

幫同事為單一商品產出後台「網路搜尋最佳化」的四欄，每欄都可以直接複製貼上。

## 只產這四欄（2026-10-10 起）

後台位置：商品 → 編輯該商品 → 網路搜尋最佳化。

1. **標題**：Google 搜尋結果上的藍色大標。
2. **簡介**：Google 搜尋結果上的那段說明。⚠️ 不會顯示在商品頁上，逛頁面的人看不到。
3. **關鍵字**
4. **描述性網址**：商品頁網址的英文部分。

⛔ **不產這三樣**：商品名稱、商品摘要、商品描述（不論是積木文字還是 HTML）。
- 商品描述和商品摘要改用「上架工具」產生，這一版的文案由美編自己寫。
- 使用者要這幾樣時，先回一句：「商品描述和商品摘要請用上架工具做；這個 skill 只產商品頁設定的四欄。」再問對方要不要產這四欄，要的話才照下面的流程問資訊。
- 不要自己寫商品描述、商品摘要或 HTML，就算使用者再要一次也一樣。
- 商品名稱由美編自己定，不代寫。使用者有給，就當成素材用。

## 流程

1. **先確認資訊**。缺的主動問，問齊了才產：
   - 商品名稱（含品牌）、品類
   - 3 到 5 個賣點
   - **適用機型那一行**（有相容性的品類才要）：請使用者到上架工具的「商品摘要」分頁，複製「適用機型」那一行貼過來。
     - ⚠️ 不要從商品名稱或賣點自己推算機型，也不要自己補「12–18 系列」這種範圍。
     - 沒有那一行時（例如這個商品不是用工具做的），請使用者貼「規格選單上的機型清單」，照 `reference/seo-geo-rules.md` §2.1 整理。
     - 通用品（掛繩、支架、線材⋯）回答「不挑機型」就好。
   - 目標關鍵字（可選，沒給就照品類推）
2. **讀規則檔**：
   - `reference/seo-geo-rules.md`：必讀，四欄的寫法、品類快查表、自我檢查清單都在這裡。
   - `reference/brand-voice.md`：選讀。⚠️ 這個檔不在公開下載包裡（含品牌策略，屬內部文件），有才讀。沒有也能跑，但語氣的護欄會少一層，產出要人工看過。
3. **產出**：四欄各一個程式碼框，方便一鍵複製。
4. **交出前，逐條對 `seo-geo-rules.md` 最後的「自我檢查清單」**。有一條不符合，先改好再交。
5. **提醒**：改了既有商品的描述性網址，要去後台設 301 轉址，不然舊連結和 Google 排名會斷。新商品不用。

## 重要原則

- 繁體中文，全形標點。
- 用同事看得懂的白話：欄位用後台的中文名（標題、簡介、關鍵字、描述性網址），不要丟 meta、slug、H2 這類術語。
- 據實：不確定的規格、機型不要編，請使用者確認。
- 促銷和限時活動不進標題，也不進簡介：Google 會把簡介留很久，活動結束後還會被看到。
- 全店品類通用（手機殼、玻璃貼、鏡頭貼、MagSafe 周邊、行動電源、快充線／快充頭、AirPods 殼、Apple Watch、iPad、掛繩、支架、車用配件⋯）。規則檔的範例多用 B67 手機殼，那是長相示範，不是品類限制。「適用機型」只用在有相容性的品類；通用品改寫品類和適用對象，不要硬編機型。
